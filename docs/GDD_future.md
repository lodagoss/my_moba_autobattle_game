# Moba自走棋项目设计文档 (GDD)

## 1. 项目概述

### 1.1 游戏简介

- 游戏类型：策略/自动战斗
- 目标平台：Steam
- 开发引擎：Godot 4.x
- 游戏规模：小品级
- 项目定位：我的第一个练手项目，计划达到较高完成度，基本实现所有常规性的游戏组件，以及自走棋的常规玩法。未来，自走棋类游戏的开发可以复用这个项目的相关组件。

### 1.2 核心玩法

- 我喜好的自走棋类游戏：
  - dota自走棋：实时、回合、羁绊
  - Super Auto Pets：异步、回合、羁绊
  - 皇室战争：实时、动态
  - 战就战：实时、动态、建筑
  - 战地指挥官：实时、动态、建筑
  - 部落冲突：异步、动态、非对称
  - 背包战争：异步、回合
  - 足球经理：放置、养成
  - Swarm Simulator、NGU IDLE、Melvor Idle：放置、养成
- 喜好游戏共性：
  - 放置：这是最大的共性，战斗部分无法直接操作
  - 策略：但战斗的结果受自己的决策影响
  - PvP：不管同步还是异步，要与对手玩家开展策略博弈
  - 成长：升级、loot、局内局外养成
- 项目核心玩法：
  - 战斗过程：模拟moba游戏，但是是自动战斗。本游戏实际是回合制，moba游戏中的1分钟就是本游戏的1回合。每回合，英雄根据玩家局前设置的偏好，自动按一定概率进行决策，例如补兵、磨血、推线、gank、打野等，每个策略会对这一回合的战斗结果产生影响，例如如果补兵，则可以获得更多金币，如果磨血，则可更多降低对方血量。每方5名英雄。推掉基地获胜。
  - 赛前设置：玩家在赛前设置5名英雄的类型和战斗偏好。
  - 局外养成：胜利后的奖励，可以用来购买、升级英雄，扩大策略选择种类，提升策略效果。
  - 支持PvE、异步PvP

### 1.3 开发原则

- 高完成度：需要有菜单、HUD、音效、音乐等功能，确保达到练习效果。
- 可复用可扩展：为后续自走棋项目打好基础。
- 快速开发：不要拘泥于细节，快速实现功能，防止烂尾。

  - 装备与等级成长系统

- 地图系统：

  - 建筑
  - 路径
  - 寻路系统（未来）
  - 视野系统（未来）
  - 野怪（未来）

- 策略系统：

  - 策略配置器：配置英雄策略

## 2. 游戏系统

### 2.1 基础机制

- 游戏地图：简化版MOBA地图，包含三路、建筑
- 回合机制：一回合相当于MOBA游戏1分钟
- 经济系统：
  - 补兵收益
  - 击杀收益
  - 推塔收益
  - 野怪收益（未来）

### 2.2 英雄系统

- 基础属性：
  - 生命值
  - 攻击力
  - 移速
  - 攻击范围
- 行为：
  - farm(up,mid,down,close,far)
  - push(up,mid,down,close,far)
  - gank(up,mid,down,close,far)
  - poke(up,mid,down,close,far)
  - move_to(up,mid,down,close,far,home)
- 英雄：
  - 坦克
  - 战士
  - 法师
  - 刺客
  - 射手
  - 辅助
- 成长系统：
  - 等级提升
  - 装备购买
  - 技能升级（未来）

### 2.3 策略系统

- 可拖选游戏时间，指定该时间段内英雄的策略
- 策略：
  - 推线
  - 支援
  - 打野

### 2.4 战斗系统

- 回合内行为：
  - 补兵
  - 推线
  - 支援
  - 打野
  - 团战
