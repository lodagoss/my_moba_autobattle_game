# Moba自走棋项目设计文档 (GDD)——第一期

## 1. 项目概述

### 1.1 游戏简介

- 游戏类型：策略/自动战斗
- 目标平台：Steam
- 开发引擎：Godot 4.x
- 游戏规模：小品级
- 项目定位：类足球经理，模拟moba，注重自动战斗和策略系统。第一期实现最简单的地图、战斗系统、兵线系统、装备系统、AI。

### 1.2 核心玩法

- 项目核心玩法：
  - 模拟moba游戏，但大幅简化
  - 一条中路，一个英雄原型。
  - 攻击是自动的，AI、测试者只能控制走位。
  - 有兵线但没有小兵，靠近兵线越近则获得金币越多，推线速度越快。
  - 有简单的装备系统。

### 1.3 开发原则

- 可复用可扩展：为后续自走棋项目打好基础。
- 快速开发：不要拘泥于细节，快速实现功能，防止烂尾。

### 1.4 重点实现模块

- 战斗系统
  - 基础属性：生命值、攻击力、攻击范围、攻速、移动速度
  - 自动攻击：在攻击范围内优先攻击英雄，其次攻击建筑

- 兵线系统
  - 推线机制：基于与兵线的距离计算推线进度
  - 金币获取：基于与兵线的距离计算金币获取速度

- 装备系统
  - 基础装备：提供单一属性加成
  - 合成装备：由基础装备合成，提供多重属性加成
  - 装备栏：最多携带6件装备

- AI系统
  - 基础寻路：避开障碍物
  - 状态机：基于状态机实现简单的AI行为

## 2. 技术实现

### 2.1 关键系统

- 战斗系统
  - 使用Area2D实现攻击范围检测
  - 通过信号系统处理伤害计算

- 寻路系统
  - 使用Navigation2D实现基础寻路
  - 自定义寻路权重处理特殊情况

- 数据管理
  - JSON配置游戏数据
  - 使用Resource系统管理资源

## 3. 开发计划

### 3.1 第一阶段（基础系统）

1. 搭建基础框架
2. 实现战斗系统核心
3. 完成基础寻路

### 3.2 第二阶段（游戏性）
